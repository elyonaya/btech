# Jour 7 : Web Design

Découvrez les frameworks CSS !

## Exercice 4 :

À vous de la reproduire une nouvelle fois le prototype (uniquement) de votre page web, mais avec un framework !

Utilisez [Materialize CSS](https://materializecss.com/getting-started.html), suivre le guide d'installation et lisez la documentation.

### Conseils

- prenez **vraiment** votre temps pour lire et comprendre le fonctionnement d'un framework : seule votre patience et quelques tests vous permettront de comprendre comme l'utiliser
- il va être difficile (voire impossible) de reproduire à la perfection ; contentez-vous d'en approcher coté structure avant tout
- il existe d'autres frameworks que Materialize, mais tous ne se valent pas et ont des niveaux de difficultés différents ; à vos risques et périls si vous en utilisez d'autres !
