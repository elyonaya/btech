# Jour 7 : Web Design

## Exercice 2 :

Toujours sur la même page web, créez maintenant le mockup !

Vous devrez aussi le prendre en photo/le scanner et l'ajouter à ce dossier d'exercice 2.

Toujours selon votre degré de confiance, vous pouvez le réaliser sous un format :

- papier/crayon
- logiciel de wireframe

### Conseils

- Vous pouvez écrire par dessus votre wireframe, ou prendre une "nouvelle feuille".
- Vous n'avez pas à reproduire parfaitement ce site, hormis sa structure générale.
- Rappelez-vous les règles d'un mockup :
  - représentation proche du final
  - couleurs, typographies, padding, etc...
