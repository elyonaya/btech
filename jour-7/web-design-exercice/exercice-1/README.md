 Jour 7 : Web Design

## Exercice 1 :

Observez bien cette page d'accueil d'un portfolio de photographe :

![resultat](https://i.imgur.com/FWQcqQt.png)

À vous de créer son wireframe ! Vous devrez ensuite le prendre en photo/le scanner et l'ajouter à ce dossier d'exercice 1.

Selon votre degré de confiance, vous pouvez le réaliser sous un format :

- papier/crayon
- logiciel de wireframe ; un lien pour accéder au résultat ne sera pas valide. À vous d'exporter votre travail pour l'ajouter à ce dossier.

### Conseils

Rappelez-vous les règles d'un wireframe :

- visualiser la structure sans design
- pas de couleurs, marges réduites, sections nécessaires (grisé, placeholders), etc...
