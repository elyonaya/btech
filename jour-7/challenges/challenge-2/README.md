# Jour 7 : Web Design

## Challenge 2 :

Vous allez commencez à apprendre à travailler en binôme ... mais sans savoir avec qui !

Vous vous retrouverez dans un des deux groupes suivants :

- **groupe HTML** : faites uniquement le HTML (pas de CSS) dans un fichier "index.html"
- **groupe CSS** : faites uniquement le CSS (pas de HTML) dans un fichier "styles.css"

Créez la carte de profil utilisateur ci-dessous avec :

- un nom
- une profession
- une description courte
- une liste de compétences

**N'utilisez que des `div` pour structurer, et des `id` ou `class` pour identifier les éléments.**

![resultat](https://i.imgur.com/G9RSoX8.png)

## Conseils

- Vous donnerez votre travail à une autre personne par la suite : ne vous trompez pas dans le nommage de votre fichier, et pour relier du HTML à du CSS !
- Une fois terminé et votre code relu, patientez la fin du temps imparti pour les prochaines instructions.
- Ne faîtes pas la partie de l'autre groupe !
