# Jour 3 : CSS basics

## Exercice 1 :

1. Créez dans ce dossier "exercice-1" un fichier "index.html" avec :

- son **boilerplate** (la base minimale nécessaire à n'importe quelle page web)
- un **titre principal** affiché sur la page
- un **titre** affiché dans l'onglet de la page

2. Dans le même dossier, créez un fichier "styles.css" avec :

- une **couleur de texte** pour le titre

## Conseils

- Vous ne savez pas quelle balise permet de changer le titre de l'onglet ? Pensez à checker [MDN](https://developer.mozilla.org/fr/docs/Web/HTML/Element) !
- Vérifiez petit à petit le résultat sur votre navigateur.
- Aucun CSS ne s'affiche ? L'avez-vous bien relié à votre fichier HTML, comme vu pendant le cours ?
