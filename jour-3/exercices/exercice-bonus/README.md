# Jour 3 : CSS basics

## Exercice bonus

> ⚠️ Cette exercice n'est a faire que si vous avez terminé et rendu les autres exercices ⚠️

1. Créez dans ce dossier "exercice-bonus" un fichier "index.html" avec :

- un boilerplate
- un lien
- un paragraphe contenant un peu de lorem ipsum
- un en-tête (la balise, pas le `<head>`)
- un article contenant un peu de lorem ipsum
- un pied-de-page contenant un peu de lorem ipsum

2. Ajoutez dans ce fichier HTML :

- une indication au navigateur de la langue de la page web ; cela ne traduira pas la page !
- une indication au navigateur d'utiliser un alphabet de caractères universel
- une indication pour ouvrir un lien dans un autre onglet plutôt que de quitter le site en cours
- changer la couleur du texte du paragraphe, en écrivant du CSS directement dans la balise HTML ... à faire avec modération, et dans aucun autre exercice du Programme BTech (mais bon à connaître)

3. Créez dans ce même dossier un fichier "styles.css" avec :

- une façon de remettre zéro tous les styles d'une page web. Faîtes-le avant de changer les autres styles ci-dessous, même si le style directement écrit dans le HTML ne devrait pas être affecté par cette remise à zéro
- l'en-tête, l'article et le pied-de-page en rouge, [mais de trois manières différentes](https://www.w3schools.com/cssref/css_colors_legal.php)
- écrire du HTML directement dans du CSS ... à faire avec modération, et dans aucun autre exercice du Programme BTech (mais bon à connaître)
