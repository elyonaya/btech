# Jour 3 : CSS basics

## Exercice 4 :

1. Créez dans ce dossier "exercice-4" un fichier "index.html" avec :

- son **boilerplate** (sa base minimale)
- toutes les **images** présentes dans le dossier "images" :
  - ces images ne doivent pas être déplacées ou copiées autre part que dans ce dossier
  - la description de chaque image est attendue dans sa balise concernée

> **Détails des images**
>- **ocean** : photo de Ricky Esquivel
>- **mountain** : photo de Eberhard Grossgasteiger
>- **forest** : photo de Lukas Hartmann

2. Créez un fichier "styles.css" avec pour chaque image :

- une **largeur** de 400 pixels
- des **bordures** épaisses, de la couleur et du style de votre choix
- des **coins** arrondis
- une **ombre** visible

### Conseils

- Ne faîtes que du CSS dans un fichier se terminant en `.css` !
- Si vous ne savez pas quelles propriétés utiliser, pensez à checker [MDN](https://developer.mozilla.org/fr/docs/Web/CSS).
- Vérifiez petit à petit le résultat sur votre navigateur.
- Aucun CSS ne s'affiche ? L'avez-vous bien relié à votre fichier HTML, comme vu pendant le cours ?
