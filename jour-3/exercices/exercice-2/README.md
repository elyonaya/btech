# Jour 3 : CSS basics

## Exercice 2 :

1. Créez dans ce dossier "exercice-2" un fichier "index.html" avec (encore) :

- son **boilerplate** (sa base minimale)
- un **titre principal**
- un **sous-titre**
- un **paragraphe**
- un **bouton**

2. Dans le même dossier, créez un fichier "styles.css" avec :

- une **couleur de fond** de toute la page
- une **couleur de texte** pour le titre uniquement
- une **couleur de fond** pour le paragraphe
- une **couleur de fond** et une **couleur de texte** pour le bouton

> ⚠️ **Toutes** les couleurs doivent être différentes les unes des autres

## Conseils

- Si vous ne savez pas quelle balise utiliser pour un bouton, pensez à checker [MDN](https://developer.mozilla.org/fr/docs/Web/HTML/Element). Il s'agit bien d'une balise spécialement conçue pour un bouton !
- Vérifiez petit à petit le résultat sur votre navigateur.
- Aucun CSS ne s'affiche ? L'avez-vous bien relié à votre fichier HTML, comme vu pendant le cours ?
