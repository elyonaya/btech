# Jour 3 : CSS basics

## Exercice 3 :

Le site web fourni dans ce dossier "exercice-3" reprend l'exercice 6 de mardi. Cette version était uniquement en HTML, c'est maintenant l'heure de la rendre plus agréable avec du CSS !

Créez un fichier dans ce dossier "exercice-3" un fichier CSS et stylisez votre page :

- le fond de la page entière doit être **coloré**

- le titre doit être au **centre** de la page

- le texte de chaque paragraphe doit être d'**une couleur** et d'**une nouvelle police d'écriture** commune
- les articles doivent être chacun **entourés d'une bordure fine, grise et en pointillé**

- tous les liens **ne doivent plus être soulignés** et **ne plus être bleus** mais d'une autre couleur ; ils doivent par contre toujours être des liens en HTML

- la partie "Commentaire" doit avoir un fond plus clair que le fond de la page (_indice_ : regardez s'il n'y a pas une balise qui entoure le titre "Commentaire" et la liste qui va avec)
- chaque élément de liste ne doit plus avoir de "points/tirets" mais doivent toujours être des éléments de liste en HTML

> Vous avez le choix des couleurs, si elles ne sont pas indiquées dans ces consignes !

## Conseils

- Vous ne devez pas modifier le fichier "index.html".
- Ne faîtes que du CSS dans un fichier se terminant en `.css` !
- Si vous ne savez pas quelles propriétés utiliser, pensez à checker [MDN](https://developer.mozilla.org/fr/docs/Web/CSS).
- Vérifiez petit à petit le résultat sur votre navigateur.
- Aucun CSS ne s'affiche ? Avez-vous bien nommer votre fichier CSS, comme indiqué dans le fichier HTML ?
