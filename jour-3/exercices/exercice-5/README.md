# Jour 3 : CSS basics

Pour cet exercice, vous allez commencer à avoir un mini-mini-site de deux pages, avec comme challenge supplémentaire de n'utiliser qu'**un seul fichier CSS** !

## Exercice 5 :

1. Créez dans ce dossier "exercice-5" un fichier "index.html" avec :

- un **titre principal**, qui sera le nom d'un faux site blog sur le thème de la pêche
- une **liste de liens** permettant de naviguer vers :
  - la page d'accueil
  - la page d'à-propos
  - le site officiel de pêche de Wallonie : https://www.maisondelapeche.be/
- un **trait horizontal** pour séparer le haut de la page avec le reste
- un **sous-titre**, qui sera le nom de la page en cours
- un **paragraphe de présentation**, qui peut être du faux-texte dans cet exercice
- une **image** différente selon la page :
  - sur la page d'accueil : https://fastly.picsum.photos/id/13/2500/1667.jpg?hmac=SoX9UoHhN8HyklRA4A3vcCWJMVtiBXUg0W4ljWTor7s
  - sur la page d'à-propos : https://fastly.picsum.photos/id/14/2500/1667.jpg?hmac=ssQyTcZRRumHXVbQAVlXTx-MGBxm6NHWD3SryQ48G-o


2. Créez un fichier "styles.css" :

- le titre principal :
  - au **centre** de la page
  - d'une **police d'écriture** différente des listes, sous-titres et paragraphes
  - avoir le **texte couleur "vert d'eau"**

- le sous-titre :
  - d'une **police d'écriture** différente des titres principaux, listes et paragraphes
  - avoir le **texte couleur "vase"**

- le **fond** de la liste entière doit être **gris clair**

- le **texte** des éléments de liste doivent être :
  - de **couleur gris foncé**
  - en **gras** ; sans utiliser de balise HTML

- l'**image** doit avoir des **coins arrondis**

## Conseils

- Le trait horizontal est une balise HTML ; ne le faite pas en CSS.
- N'utilisez qu'un seul fichier CSS pour styiliser les deux fichiers HTML !
- Vérifiez petit à petit le résultat sur votre navigateur.
- Aucun CSS ne s'affiche ? L'avez-vous bien relié à votre fichier HTML, comme vu pendant le cours ?
