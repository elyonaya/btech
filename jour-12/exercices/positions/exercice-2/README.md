# Jour 12 : Révisions - Positions

## Exercice 2 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`positions`](https://developer.mozilla.org/fr/docs/Web/CSS/position), pas `display`, pas `flexbox`, ni `transform`.

- Créez quatre courts paragraphes (`<p>`)
- Placez ces quatre `<p>` dans un conteneur parent (autre que `<body>`)
- Donnez une hauteur de 150px au conteneur, et entourez-le d'une bordure noire
- Placez chaque paragraphe dans un coin du conteneur à l'aide d'un positionnement absolu

![resultat](https://i.imgur.com/Xl51QZ8.png)

## Conseils

- `<main>`, `<section>`, etc... sont autant de balises qui peuvent remplacer `<div>`
- N'utilisez pas de positionnements relatifs ou fixes pour les quatre paragraphes ; seulement absolus
- La largeur de la capture d'écran est volontairement réduite pour des raisons de visibilités ; vous n'avez pas besoin de changer la taille de votre navigateur.
