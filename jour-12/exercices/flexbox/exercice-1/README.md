# Jour 12 : Révisions - Flexbox

## Exercice 1 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`flexbox`](https://developer.mozilla.org/fr/docs/Web/CSS/flexbox), pas `display: inline|inline-block|block`, ni `position`.

- Créez trois `<div>` avec ou sans texte, au choix
- Placez les trois `<div>` sur une seule ligne (horizontalement), dans un nouvel élément parent qui n'est pas directement `<body>`
- Entourez chaque `<div>` d'une fine bordure bleue
- Espacez chaque `<div>` avec un peu de marge
- Entourez le conteneur des trois `<div>` d'une épaisse bordure noire

![resultat](https://i.imgur.com/vp6VhZQ.png)

## Conseils

- `<main>`, `<section>`, etc... sont autant de balises qui peuvent remplacer `<div>`
- La largeur de la capture d'écran est volontairement réduite pour des raisons de visibilités ; vous n'avez pas besoin de changer la taille de votre navigateur.
