# Jour 12 : Révisions - Flexbox

## Exercice 3 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`display`](https://developer.mozilla.org/fr/docs/Web/CSS/display), pas `position`, ni `flex`.

- Créez trois groupes de trois `<div>` chacun avec ou sans texte, au choix
- Entourez chaque groupe de trois `<div>` d'une bordure noire
- Placez chaque trois `<div>` de chaque groupe sur une ligne (verticalement), dans un nouvel élément parent chacun qui n'est pas directement `<body>`
- Donnez une couleur de fond commune à chaque `<div>` d'un même groupe, mais une couleur différente par groupe
- Espacez horizontalement les `<div>` de chaque groupe d'une manière différente

![resultat](https://i.imgur.com/RII2g01.png)

## Conseils

- `<main>`, `<section>`, etc... sont autant de balises qui peuvent remplacer `<div>` ; il faudra probablement utiliser des id et des classe pour différencier/rassembler certains styles.
- La largeur de la capture d'écran est volontairement réduite pour des raisons de visibilités ; vous n'avez pas besoin de changer la taille de votre navigateur.
