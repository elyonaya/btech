# Jour 12 : Révisions - Display

## Exercice 3 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`display`](https://developer.mozilla.org/fr/docs/Web/CSS/display), pas `position`, ni `display:flex`.

- Créez trois `<div>` vides
- Placez les trois `<div>` soient sur une seule ligne (horizontalement)
- Entourez chaque `<div>` d'une épaisse bordure verte
- Chaque `<div>` doit être un carré de taille identique
