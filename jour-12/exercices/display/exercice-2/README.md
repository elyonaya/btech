# Jour 12 : Révisions - Display

## Exercice 2 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`display`](https://developer.mozilla.org/fr/docs/Web/CSS/display), pas `position`, ni `display:flex`.

- Créez trois `<span>` avec du texte (court)
- Placez les trois `<span>` sur des lignes séparées (verticalement)
- Entourez chaque `<span>` d'une fine bordure rouge
- Chaque `<span>` doit être aussi large que la page

![resultat](https://i.imgur.com/jpnGzfU.png)

## Conseils

- Inutile de donner une largeur en pixels : différents écrans ont différentes dimensions ! [Regardez plutôt du coté des typers de valeurs en CSS](https://developer.mozilla.org/fr/docs/Web/CSS/width#valeurs).
- Une légère marge va rester entre vos éléments et les bords de la page ; vous pouvez ne pas vous en préoccuper ... ou faire un reset des marges !
- La largeur de la capture d'écran est volontairement réduite pour des raisons de visibilités ; vous n'avez pas besoin de changer la taille de votre navigateur.
