# Jour 12 : Révisions - Display

## Exercice 5 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`display`](https://developer.mozilla.org/fr/docs/Web/CSS/display), pas `position`, ni `display:flex`.

- Créez un lien `<a>` avec du texte
- Le lien soit deux fois moins large que la largeur de la page entière
- Ajoutez un arrière-plan ou une bordure pour qu'il ressemble à un bouton rectangulaire
- Ajoutez un peu de padding pour le rendre plus grand
- Toute la zone colorée de ce lien doit être cliquable et doit mener vers "#"
