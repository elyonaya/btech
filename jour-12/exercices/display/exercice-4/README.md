# Jour 12 : Révisions - Display

## Exercice 4 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`display`](https://developer.mozilla.org/fr/docs/Web/CSS/display), pas `position`, ni `display:flex`.

- Créez deux `<div>` avec du texte ou vides, au choix
- Les deux `<div>` doivent être séparées par une [ligne horizontale](https://developer.mozilla.org/fr/docs/Web/HTML/Element/hr)
- La première `<div>` ne DOIT pas être affichée ; via du CSS, sa place doit être inexistante et la seconde `<div>` doit pouvoir "remonter" dans le flux de la page

> L'espace au-dessus de la ligne horizontale sur la capture d'écran ci-dessus est bien le bord supérieur de la page.
