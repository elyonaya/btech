# Jour 12 : Révisions - Display

## Exercice 1 :

> Pour cet exercice, vous aurez besoin d'utiliser les propriétés de [`display`](https://developer.mozilla.org/fr/docs/Web/CSS/display), pas `position`, ni `display:flex`.

- Créez trois `<div>` avec du texte (court)
- Placez les trois `<div>` sur une seule ligne (horizontalement)
- Entourez chaque `<div>` d'une fine bordure bleue
- Chaque `<div>` doit être naturellement aussi large que son contenu (le texte à l'intérieur) ; pas besoin de le redimensionner vous-même
