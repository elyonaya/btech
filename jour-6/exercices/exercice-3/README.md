# Jour 6 : Flexbox

Cette fois-ci, gardons les items alignés **horizontalement**, mais dans le **sens inverse** !

## Exercice 3 :

Reprenez le même code que l'un des deux exercices précédents, mais :
- les items doivent alignés horizontalement, depuis la droite
- les items doivent être disposés dans le sens inverse :
  - l'item n°3
  - puis l'item n°2
  - et enfin l'item n°1

> ⚠️ Vous ne devez pas changer l'ordre des balises dans votre code HTML, mais utilisez plutôt l'une des propriétés de `display: flexbox` !
