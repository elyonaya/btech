# Jour 6 : Flexbox

> ⚠️ N'utilisez que **flexbox** et ses propriétés pour gérer les différents placements des éléments ; pas de `inline`, `block`, `inline-block`, `float`, `grid` ou "forcer" des margins autour d'un élément pour le placer.

## Exercice 1 :

1. Créez un fichier "index.html" avec une `<div>` (ie. un container) contenant trois items (ie. trois éléments de texte comme des `<div>`, des `<span>`, des `<p>`, etc... au choix !)

2. Créez un fichier "styles.css" avec :
- pour la `<div>` qui englobe les trois items :
  - avec ces trois items alignés de façon horizontale
  - une largeur de 500px
  - une hauteur de 120px
  - une bordure de couleur
  - une marge autour
- pour chacun des trois items :
  - une couleur de fond différente à chaque item
  - une légère marge autour

## Conseils

- Le résultat sur la capture d'écran est une approximation ; inutile d'essayer de faire "parfait" !
- Perdu dans toutes les propriétés de flex ? Refaîtes un tour au début de l'exercice 0 et allez vous entraîner avec une certaine grenouille ...
- Vous ne savez plus comment donner du style à différentes balises du même type ? Il est temps de revoir [les class](https://developer.mozilla.org/fr/docs/Web/CSS/Class_selectors) et [les id](https://developer.mozilla.org/fr/docs/Web/CSS/ID_selectors).
