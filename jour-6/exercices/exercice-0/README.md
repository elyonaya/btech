## Exercice 0 : Testez vos connaissances !

Répondez aux questions ci-dessous, en supprimant les réponses qui vous semblent incorrectes pour ne laissez que l'unique bonne réponse.

---

**Quelle propriété et valeur sont utilisées pour créer un container flex ?**

2. `display: flex`

---

**Quels sont les composants d'une flexbox ?**

1. Seulement des balises parents

---

**Quelle réponse est correcte ?**

1. `.container { display: flex; }`

---

**Quelle propriété et valeur de flexbox permettent de mettre des éléments en colonne ?**

3. `flex-direction: column;`

---

**Quelle propriété et valeur permettent de centrer des éléments sur la ligne horizontale ?**

2. `justify-content: center;`

---

**Quelle propriété et valeur permettent de placer des éléments en bas d'un container flex ?**

1. `align-items: flex-end;`

---

**Que fait le code suivant ?**

```css
div {
  display: flex;
  height: 300px;
  justify-content: center;
  align-items: center;
}
```

3. Il centre parfaitement les items de `<div>` horizontalement et verticalement
