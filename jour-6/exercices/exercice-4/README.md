# Jour 6 : Flexbox

Cette fois-ci, les items alignés **verticalment** doivent être dans le **sens inverse** !

## Exercice 4 :

Reprenez le même code que l'un des exercices précédents, mais :
- les items doivent alignés verticalement, depuis le bas
- les items doivent être disposés dans le sens inverse :
  - l'item n°3
  - puis l'item n°2
  - et enfin l'item n°1

> ⚠️ Vous ne devez pas changer l'ordre des balises dans votre code HTML, mais utilisez plutôt l'une des propriétés de `display: flexbox` !
