# Jour 10 : Positions

## Exercice bonus 1 :

Reprenez le code de votre exercice 1 :

1. affichez le bloc (ie. le second paragraphe) **en dessous** du texte du premier paragraphe lorsqu'on ne passe pas la souris sur ce bloc
2. affichez le bloc **par dessus** le texte du premier paragraphe lorsqu'on passe la souris par dessus - le premier paragraphe
3. ajoutez un effet de **transition** à ce changement

![resultat](https://i.imgur.com/InXTcLU.gif)

### Conseil

Vous aurez besoin d'une [combinaison de sélecteurs](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_selectors/Selectors_and_combinators) selon l'une des deux façons permettant d'atteindre le résultat attendu :
1. soit passer la souris par-dessus le container
2. soit "vraiment" passer la souris sur le paragraphe
