# Jour 10 : Positions

## Exercice bonus 2 :

Reprenez le code de votre exercice 2 :

0. (si vous ne l'aviez pas encore effectué : **centrez verticalement et horizontalement** le texte dans le cercle)
1. ajoutez un **titre principal** avant votre paragraphe
2. ajoutez un **lien** *autour* de votre cercle et faîtes que ce lien ramène au titre principal
3. ajoutez un léger **effet de zoom** sur le cercle lorsqu'on passe la souris par-dessus
4. ajoutez un changement de **couleur de fond** lorsqu'on **clique** (et maintient le clic) sur le cercle
5. ajoutez une **transition** aux derniers précédents effets
6. trouvez comment ajouter un genre de **transition fluide pour "remonter"** vers le titre. Il ne s'agit pas vraiment d'une transition, et vous n'avez pas besoin de Javascript pour y parvenir.
