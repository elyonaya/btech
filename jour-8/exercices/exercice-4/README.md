# Jour 8 : Transitions

## Exercice 4 :

Créez un fichier "index.html" avec un **paragraphe** de texte

Créez un fichier "styles.css" avec pour le texte :

- une **largeur** de 200 pixels
- une **couleur de fond** (au choix)
- un léger **padding** (par exemple 10 pixels)
- une **marge à gauche** négative de 150 pixels

- un **changement de bordure** lorsqu'on **passe la souris dessus** :
  - une **marge à gauche** de 30 pixels ; doit donner l'impression que le texte "sort" de la gauche de l'écran
  - un changement qui **démarre** immédiatement
  - une **durée de changement** de 0,3 seconde
  - un **effet de changement** au choix, différent de celui par défaut

![résultat](https://i.imgur.com/NXDiQSa.gif)

### Conseils

- N'essayez pas de reproduire à la perfection :

  - référez plutôt aux consignes
  - le gif ci-dessus est ralenti, du fait de l'encodage : basez-vous plutôt sur les consignes pour la durée et le délai

- 0,3 seconde est extrêmement court, mais perceptible par notre cerveau. Vous pouvez mettre une plus grande valeur le temps de coder votre exercice.
