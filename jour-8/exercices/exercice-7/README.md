# Jour 8 : Animations

## Exercice 7 :

Créez un fichier "index.html" avec une **div** vide

Créez un fichier "styles.css" avec pour la div :

- une **largeur** de 0 pixel par défaut
- une **hauteur** de 20 pixels
- une **couleur de fond**

- un **allongement** de la largeur de la div lorsqu'on **arrive sur la page**
- une animation qui **démarre** immédiatement
- une **durée d'animation** de 3 secondes
- une **répétition infinie**

![résultat](https://i.imgur.com/ilNWM3M.gif)

### Conseils

- N'essayez pas de reproduire à la perfection :

  - référez plutôt aux consignes
  - le gif ci-dessus est ralenti, du fait de l'encodage : basez-vous plutôt sur les consignes pour la durée et le délai
