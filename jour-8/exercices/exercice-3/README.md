# Jour 8 : Transitions

## Exercice 3 :

Créez un fichier "index.html" avec une **image**

Créez un fichier "styles.css" avec :

- l'image ayant une **largeur** de 300 pixels et une **opacité** de 0.3 par défaut

- un **changement d'opacité** de l'image à 1 lorsqu'on **passe la souris dessus**
- un changement qui **démarre** immédiatement
- une **durée de changement** de 0,5 seconde
- un **effet de changement** "doux à la fin"

![résultat](https://i.imgur.com/OEnLXBM.gif)

### Conseils

- N'essayez pas de reproduire à la perfection :

  - référez plutôt aux consignes
  - le gif ci-dessus est ralenti, du fait de l'encodage : basez-vous plutôt sur les consignes pour la durée et le délai

- Pour éviter que l'image ne soit trop lourde dans votre dossier, utiliser une image libre de droit en ligne comme sur [Lorem Picsum](https://picsum.photos/)

- 0,5 seconde est extrêmement court, mais perceptible par notre cerveau. Vous pouvez mettre une plus grande valeur le temps de coder votre exercice.
