# Jour 8 : Animations

## Exercice bonus :

Créez une page "catalogue" :

### Étape 1

La page doit avoir :

- navbar contenant un titre
- deux cards :
  - sous-titre
  - paragraphe
  - bouton
- un style basique de votre choix, incluant couleurs, paddings, margins, etc...

### Étape 2

Les deux cards doivent :

- être alignées horizontalement, côte à côte
- dans chacune des cards :
  - alignez tous les éléments en colonne, centrés horizontalement et verticalement

### Étape 3

Ajoutez les éléments :

- deux boutons dans la navbar à côté du titre
- ajoutez un effet de transition sur :
  - les boutons de la navbar et ceux des cards
  - les cards entières (lorsqu'on les survolera avec la souris)

### Étape 4

Dupliquez les lignes de cards, toujours 2 par 2, sur au moins 3 lignes.

### Conseils

- Pas d'image "résultat" : à vous de jouer avec les consignes et votre propre style !
- Les différentes étapes sont des suggestions pour ne pas aller trop vite, faire trop complexe en une seule fois.
- N'hésitez pas à soit créer plusieurs fichiers par étapes, soit à venir montrer la progression de votre travail petit à petit, durant le cours.
