# Jour 8 : Animations

## Exercice 6 :

Créez un fichier "index.html" avec un **paragraphe de texte**

Créez un fichier "styles.css" avec pour le paragraphe :

- une **changement de couleur** de texte lorsqu'on **arrive sur la page**
- une animation qui **démarre** immédiatement
- une **durée d'animation** de 2 secondes
- cinq **répétition**

![résultat](https://i.imgur.com/JUoMuAp.gif)

### Conseils

- N'essayez pas de reproduire à la perfection :

  - référez plutôt aux consignes
  - le gif ci-dessus est ralenti, du fait de l'encodage : basez-vous plutôt sur les consignes pour la durée et le délai
