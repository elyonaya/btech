# Jour 8 : Animations

## Exercice 5 :

Créez un fichier "index.html" avec un **bouton**

Créez un fichier "styles.css" avec pour le bouton :

- une **changement de couleur** au bouton lorsqu'on **arrive sur la page**
- une animation qui **démarre** immédiatement
- une **durée d'animation** de 5 secondes
- une seule **répétition** ; le bouton doit changer une seule fois de couleur et revenir à la couleur par défaut

![résultat](https://i.imgur.com/8j89bFJ.gif)

### Conseils

- N'essayez pas de reproduire à la perfection :

  - référez plutôt aux consignes
  - le gif ci-dessus est ralenti, du fait de l'encodage : basez-vous plutôt sur les consignes pour la durée et le délai

- 0,3 seconde est extrêmement court, mais perceptible par notre cerveau. Vous pouvez mettre une plus grande valeur le temps de coder votre exercice.
