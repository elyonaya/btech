# Jour 8 : Transitions

## Exercice 1 :

Créez un fichier "index.html" avec un **bouton**

Créez un fichier "styles.css" avec :

- un **changement de couleur** au bouton lorsqu'on **passe la souris dessus**
- un changement qui **démarre** immédiatement
- une **durée de changement** de 0,3 seconde
- un **effet de changement** "doux"

![résultat](https://i.imgur.com/XIB6NxM.gif)

### Conseils

- N'essayez pas de reproduire à la perfection :

  - référez plutôt aux consignes
  - le gif ci-dessus est ralenti, du fait de l'encodage : basez-vous plutôt sur les consignes pour la durée et le délai

- Si vous n'êtes pas sûr de la balise à utiliser pour un bouton, regardez l'exemple sur [la documentation sur MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/button#examples_2)

- 0,3 seconde est extrêmement court, mais perceptible par notre cerveau. Vous pouvez mettre une plus grande valeur le temps de coder votre exercice.
