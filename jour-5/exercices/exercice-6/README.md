# Jour 5 : Box-model

## Exercice 6 :

Après les **cards**, voici un autre élément que vous utiliserez tout le temps : les **barres de navigation** (**"_navbar_"**) !

1. Créez un fichier "index.html" avec :
  - une liste de liens **sur une même ligne** ; ils **mèneront** aux différents titres décrits ci-dessous
  - quatre titres avec un **id** chacun
  - un paragraphe en dessous de chaque titre

2. Créez un fichier "styles.css" avec :
  - une couleur de fond à la liste de lien
  - chaque lien ne doit plus avoir sa couleur d'origine, ni de soulignement

Voici à quoi doit ressembler le résulat : ![résultat](https://i.imgur.com/Wif9t4L.png)

### Conseils

- Pour "coller" la navbar contre les bords de l'écran ... à vous de chercher !
- Le résultat sur la capture d'écran est une approximation ; inutile d'essayer de faire "parfait" !
- Codez petit à petit, et testez sur votre navigateur régulièrement.
