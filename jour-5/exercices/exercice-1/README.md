# Jour 5 : Box-model

## Exercice 1 :

Créez un fichier "index.html" avec :

- quatre **paragraphes**

Créez un fichier "styles.css" avec :

- pour chacun des paragraphes :

  - une **couleur de fond** différente

- pour le premier paragraphe :

  - une **largeur** de 200 pixels
  - une **hauteur** de 50 pixels

- pour le deuxième paragraphe :

  - un **espace entre le texte et la bordure** de 50 pixels, de tous les cotés

- pour le troisième paragraphe :

  - une **bordure** noire de 5 pixels d'épaisseur

- pour le quatrième paragraphe :

  - un **espace à l'extérieur de la bordure** de 50 pixels, de tous les cotés

Le résultat devrait ressembler à ceci : ![résultat](https://i.imgur.com/UFTSg3a.png)

### Conseils

- Le résultat sur la capture d'écran est une approximation ; inutile d'essayer de faire "parfait" !
- La largeur totale des paragraphes est réduite sur la capture d'écran pour des raisons de lisibilité ; vous n'avez pas besoin de la modifier.
- Si le texte "déborde" de sa boîte, c'est soit :
  - parce que la taille de la boîte est trop petite
  - le texte est trop grand par rapport à la boîte
