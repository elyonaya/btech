# Jour 5 : Box-model

## Exercice 3 :

Plutôt qu'une liste, comme dans l'exercice 2, n'utilisez que des `<div>` ou des `<span>` !

Le résultat doit être le même que l'exercice précédent : ![résultat](https://i.imgur.com/osZhQBE.png)

### Conseils

Si vous ne vous souvenez plus de la différence, lisez la documentation sur MDN pour [`<div>`](https://developer.mozilla.org/fr/docs/Web/HTML/Element/div) ou [`<span>`](https://developer.mozilla.org/fr/docs/Web/HTML/Element/span) ! Sinon, vous pouvez toujours changer le `display` de l'un ou de l'autre.
- Le résultat sur la capture d'écran est une approximation ; inutile d'essayer de faire "parfait" !
- Codez petit à petit, et testez sur votre navigateur régulièrement.
