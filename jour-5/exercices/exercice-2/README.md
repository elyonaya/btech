# Jour 5 : Box-model

## Exercice 2 :

1. Créez un fichier "index.html" avec une **liste de trois éléments**

2. Créez un fichier "styles.css" avec pour chaque élément de la liste :
  - une couleur de fond commune
  - pas de "points" en début de ligne
  - 24 pixels d'espace entre eux
  - le texte aligné au centre horizontalement
  - disposez horizontalement, sur la même ligne

Le résultat devrait ressemble à ceci : ![résultat](https://i.imgur.com/osZhQBE.png)

### Conseils

- Le résultat sur la capture d'écran est une approximation ; inutile d'essayer de faire "parfait" !
- Pour aligner les éléments ou le texte, vous ne devez pas utiliser `display: flex;`.
- Pensez toujours à tester sur votre navigateur.
