# Jour 5 : Box-model

> ⚠️ Il s'agit d'un exercice bonus, à faire uniquement lorsque vous aurez d'abord terminé tous les exercices "normaux" !

## Exercice 1 bonus :

1. Créez un fichier "index.html" avec sept **paragraphes**

2. Créez un fichier "styles.css" avec :

- pour **chacun des paragraphes**, ajoutez-leur une **couleur de fond** différente via un id

- pour le **premier paragraphe**, ajoutez une classe `first` :
  - une **largeur** de 200 pixels
  - une **hauteur** de 50 pixels

- pour le **deuxième paragraphe**, ajoutez les classes :
  - `first`
  - `second` : un **espace entre le texte et la bordure** de 50 pixels, de tous les cotés

- pour le **troisième paragraphe**, ajoutez la classe `third` pour faire **disparaitre** le paragraphe ; checkez cette [documentation](https://developer.mozilla.org/fr/docs/Web/CSS/display) pour trouver un moyen de le faire sans supprimer la balise HTML, changer son texte, sa couleur ou sa taille.

- pour le **quatrième paragraphe**, ajoutez les classes :
  - `first`
  - `second`
  - `fourth` : une **bordure** noire de 5 pixels d'épaisseur

- pour le **cinquième paragraphe**, ajoutez la classe `fifth` pour rendre **invisible** le paragraphe ; checkez cette [documentation](https://developer.mozilla.org/fr/docs/Web/CSS/visibility) pour trouver un moyen de le faire sans supprimer la balise HTML, changer son texte, sa couleur ou sa taille.

- pour le **sixième paragraphe**, ne lui mettez aucune classe ; seulement son id pour changer de couleur de fond

- pour le **septième paragraphe**, ajoutez les classes :
  - `first`
  - `second`
  - `fourth`
  - `seventh` : un **espace à l'extérieur de la bordure** de 50 pixels, de tous les cotés

Le résultat final devrait ressembler à ceci : ![résultat](https://i.imgur.com/6CB93Bn.png)

### Conseils

- Le résultat sur la capture d'écran est une approximation ; inutile d'essayer de faire "parfait" !
- La largeur totale des paragraphes est réduite sur la capture d'écran pour des raisons de lisibilité ; vous n'avez pas besoin de la modifier.
- Codez petit à petit, et testez sur votre navigateur régulièrement.
