# Jour 5 : Box-model

## Exercice 5 :

Recommençez l'exercice précédent, mais en ajoutant paddings et margins !

1. Créez un fichier "index.html" avec :

- dans un **container** :
  - un **en-tête**
  - un **contenu principal**
  - un **pied-de-page**

2. Créez un fichier "styles.css" avec :

- pour le **container** :
  - une largeur totale de 500 pixels
  - une bordure de 2 pixels gris
  - une couleur de fond gris clair
- pour l'**en-tête** :
  - centré et gras
  - une bordure de 2 pixels rouge
  - une couleur de fond rouge clair
  - un margin (espace entre son contenu et sa bordure) de 20 pixels
- pour le **contenu principal** :
  - centré et italique
  - une bordure de 3 pixels vert
  - une couleur de fond vert clair
  - un margin de 16 pixels en haut et en bas, et de 8 pixels à gauche et à droite
- pour le **pied-de-page** :
  - centré
  - une bordure de 2 pixels bleue
  - une couleur de fond bleu clair
  - un margin de 8 pixels

Voici à quoi doit ressembler le résulat : ![résultat](https://i.imgur.com/zbHORjg.png)

### Conseils

- Si vous ne connaissez pas certaines balises comme "en-tête", "pied-de-page", etc ... faîtes l'exercice 4 ! Si vous coincez toujours, demandez de l'aide pour les balises sémantiques.
- Le résultat sur la capture d'écran est une approximation ; inutile d'essayer de faire "parfait" !
- Codez petit à petit, et testez sur votre navigateur régulièrement.
