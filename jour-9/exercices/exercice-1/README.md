# Jour 9 : Transform

## Exercice 1 :

Créez un fichier "index.html" avec une **div**.

Créez un fichier "styles.css" pour que votre div soit :

- de la forme d'un **carré**
- avec un **fond de couleur**
- **décalé** de 120 pixels vers le bas et 50 pixels vers la droite (uniquement avec `transform`) par rapport à son point d'origine

![résultat](https://i.imgur.com/xFhHFkn.png)

### Conseil

Utilisez uniquement `transform` pour déplacer l'élément.
