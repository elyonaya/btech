# Jour 9 : Transform

## Exercice 3 :

Créez un fichier "index.html" avec une **div**.

Créez un fichier "styles.css" pour que votre div soit :

- de la forme d'un **cercle**
- avec une **bordure** (couleur, épaisseur et style au choix)
- **élargissez** ce cercle de 20% de plus que sa taille d'origine (uniquement avec `transform`)

![résultat](https://i.imgur.com/w7ExIls.png)

### Conseils

- N'essayez pas de reproduire à la perfection : référez-vous plutôt aux consignes.
- Utilisez uniquement `transform` pour agrandir l’élément.
