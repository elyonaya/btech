# Jour 11 : Responsive

## Exercice 4 :

1. Créez un fichier "index.html" avec :
  - une **barre de navigation** contenant au moins 3 **liens**
  - un **contenu principal** avec **un grand titre** et au moins **un paragraphe**

2. Créez un fichier "styles.css" avec :
  - des **media queries**, la **barre de navigation** doit :

    - s'afficher **verticalement à gauche** de l'écran sur les écrans **petits** ou **larges** :
      ![desktop](https://i.imgur.com/VhD0bS0.png)

    - s'afficher **horizontalement en haut** de l'écran sur les écrans plus **petits** que précédemment (tablettes ou moins) :
      ![mobile](https://i.imgur.com/MGRe1K2.png)

### Conseils

- N'essayez pas de reproduire à la perfection : référez-vous plutôt aux consignes.
- N'oubliez pas d'ajouter un petit quelque chose dans le [`<head>`](https://developer.mozilla.org/fr/docs/Learn/CSS/CSS_layout/Responsive_Design#la_balise_m%C3%A9ta_viewport) pour éviter certains problèmes !
