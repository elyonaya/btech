# Jour 11 : Responsive

## Exercice 2 :

1. Créez un fichier "index.html" avec un `<body>` vide

2. Créez un fichier "styles.css" avec :
  - des **media queries** pour changer **la couleur de fond de la page** selon la largeur de l'écran :
    - fond rouge quand la largeur convient au format *mobile*
    - fond vert quand la largeur convient au format *tablette*
    - fond bleu quand la largeur convient au format *ordinateur portable*
    - *autrement*, la couleur de fond doit être celle d'origine

### Conseils

- N'oubliez pas d'ajouter un petit quelque chose dans le [`<head>`](https://developer.mozilla.org/fr/docs/Learn/CSS/CSS_layout/Responsive_Design#la_balise_m%C3%A9ta_viewport) pour éviter certains problèmes !
- Pas de capture d'écran pour comparer votre résultat : à vous de le faire avec les **DevTools** !
