# Jour 11 : Responsive

## Exercice 3 :

1. Créez un fichier "index.html" avec **trois div**

2. Créez un fichier "styles.css" avec :
  - une **couleur de fond** différente pour chaque div
  - les trois div doivent être **alignées sur la même ligne**, **côte à côte**, **centrées horizontalement** et **verticalement** par rapport à la page (ie. le `<body>`)
  - des **media queries** pour changer **l'alignement des div** selon la largeur de l'écran :
    - sur la même ligne, dans l'ordre, sur des *ordinateurs fixes*
    - trois sur la même ligne, dans l'ordre inverse, sur des *ordinateurs portables*
    - trois en colonne, dans l'ordre, sur des *tablettes*
    - trois en colonne, dans l'ordre inverse, sur *mobile*

### Conseils

- N'oubliez pas d'ajouter un petit quelque chose dans le [`<head>`](https://developer.mozilla.org/fr/docs/Learn/CSS/CSS_layout/Responsive_Design#la_balise_m%C3%A9ta_viewport) pour éviter certains problèmes !
- Si vous avez un oubli pour "inverser" les div, il est alors temps de réviser les propriétés CSS de [Flexbox](https://developer.mozilla.org/fr/docs/Glossary/Flexbox#propri%C3%A9t%C3%A9s_css_correspondantes) !
- Votre écran est "trop grand" ou "pas assez petit" lors de vos tests ? Utilisez plutôt l'inspecteur !
