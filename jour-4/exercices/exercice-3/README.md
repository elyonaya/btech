# Jour 4 : CSS Selectors

## Exercice 3 :

Créez un fichier "index.html" avec :

- son **boilerplate**
- quatre **paragraphes**

Créez un fichier "styles.css" avec :

- quatre **id**, de manière à ce que chaque paragraphe ait un style différent :
  - le premier doit être en **gras**
  - le second doit être en **italique**
  - le troisième doit être **souligné**
  - le quatrième doit être **barré**

## Conseils

- Si vous avez bien lu : on ne devra pas utiliser directement un sélecteur de type "**balise**".
- Ne vous fiez pas qu'au résultat dans le navigateur : relisez les consignes et relisez votre code !
