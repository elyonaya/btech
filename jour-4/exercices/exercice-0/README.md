# Jour 4 : CSS Seletors

## Exercice 0 : Testez vos connaissances !

Répondez aux questions ci-dessous, en supprimant les réponses qui vous semblent incorrectes pour ne laissez que l'unique bonne réponse.

---

**Quel sélecteur (CSS) permet de sélectionner un élément avec son id ?**

3. un dièse : `#`

---

**Quelle réponse permet de mettre le texte des `<h4>` en rouge ?**

4. `h4 { color: red; }`

---

**Comment mettre le texte de l'élément avec un id `introduction` en bleu ?**

3. `#introduction { color: blue; }`

---

**Quelle réponse permet de mettre tous les éléments avec une classe `important` en italique ?**

3. `.important { font-style: italic; }`

---

**Comment grouper tous les h1 et h2 pour les centrer ?**

2. `h1, h2 { text-align: center; }`
