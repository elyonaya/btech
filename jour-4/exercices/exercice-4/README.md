# Jour 4 : CSS Selectors

## Exercice 4 :

Créez un fichier "index.html" avec :

- son **boilerplate**
- une **liste non-ordonnée** avec :
  - quatre éléments de liste
- une **liste ordonnée** avec :
  - quatre éléments de liste

Créez un fichier "styles.css" avec :

- pour la **liste non-ordonnée** et **ordonnée** :
  - à l'aide d'une **même classe** :
    - retirez les "**puces**" (remplacez le point ou le tiret en début d'élément de liste par un autre) et **chiffres**
    - ajoutez une **bordure** autour de chaque liste
  - à l'aide d'un **id** chacun : mettez une **couleur de fond** différente l'un de l'autre
- pour les **éléments de liste** (des listes ordonnées et non-ordonnées) :
  - à l'aide d'une **même classe** :
    - le premier et le troisième doivent avoir une **couleur de texte** en rouge
    - le second et le quatrième doivent avoir une **couleur de texte** en bleu

![résultat](https://i.imgur.com/9tdc7Um.png)

### Rappels

- N'utilisez que des classes ou des ids !
- Ne faîtes pas attention à la largeur des listes sur la capture d'écran ; inutile d'essayer de changer la largeur des vôtres.
- Ne vous fiez pas qu'au résultat dans le navigateur : relisez les consignes et relisez votre code !
