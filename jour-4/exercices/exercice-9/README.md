# Jour 4 : CSS Selectors

## Exercice bonus : faire moins, c'est faire plus !

Le code CSS donné dans ce dossier d'exercice est plus compliqué qu'il ne devrait l'être : **modifiez-le**, **simplifiez-le**, tout en gardant le même résultat !

![resultat](https://i.imgur.com/OtaA1bb.png)

### Conseils

- Vous n'avez pas besoin de comprendre tous le CSS donné, seulement les **sélecteurs** associés.
- Vous n'êtes plus obligé de n'utiliser que des ids ou des classes dans cet exercice. Vous pouvez donc réutiliser des sélecteurs de **balise**.
