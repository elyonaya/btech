# Jour 4 : CSS Selectors

> ⚠️ Il s'agit d'un exercice bonus, à faire uniquement lorsque vous aurez d'abord terminé tous les exercices "normaux" !

## Exercice 3 bonus :

Copiez/collez votre fichier HTML et CSS de l'exercice 3 "normal" :

- **remplissez** vos paragraphes en ajoutant du texte à l'intérieur, de manière à pouvoir faire défiler la page
- ajoutez ensuite, avant les paragraphes, une **liste de quatre éléments** :
  - les éléments de liste doivent avoir une "**puce**" **différente de la normale**
  - chaque élément de liste doit être un **lien**, et ces lien doivent :
    - avoir **le texte bleu ciel** par défaut
    - avoir **le texte bleu foncé** et **en italique** lorsqu'on passe la souris dessus
  - chaque lien doit **mener** vers un paragraphe

## Conseil

Pour facilement remplir vos paragrpahes, utiliser du faux texte, comme du *lorem ipsum* !
