# Jour 4 : CSS Selectors

> ⚠️ Il s'agit d'un exercice bonus, à faire uniquement lorsque vous aurez d'abord terminé tous les exercices "normaux" !

## Exercice 5 bonus :

Copiez/collez votre fichier HTML et CSS de l'exercice 5 "normal" :

- ajoutez un changement de **couleur de fond** de la **liste** lorsqu'on **passera** la souris dessus
- ajoutez un changement de **couleur de fond** d'un **bouton** lorsqu'on **passera** la souris sur un élément de la liste :
  - le 1er élément de la liste doit changer la couleur de fond du 1er bouton
  - le 2eme élément de la liste doit changer la couleur de fond du 2eme bouton
  - le 3eme élément de la liste doit changer la couleur de fond du 3eme bouton

## Conseil

Pour réussir la dernière partie de l'exercice, vous aurez besoin de découvrir un nouveau type de sélection, que vous pouvez chercher sur [cette page de document de MDN](https://developer.mozilla.org/fr/docs/Web/CSS/CSS_selectors) !
