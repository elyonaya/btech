# Jour 4 : CSS Selectors

## Exercice 1 :

Avant de voir les classes et les ids, révisons comment sélectionner avec des balises : pour cet exercice, faîtes comme vous l'avez appris la semaine dernière : sans classes ni ids !

Utilisez le fichier "index.html" existant, et créez un fichier "styles.css" pour :

- que tous les **paragraphes** aient une **couleur de fond** en vert
- que tous les **liens** aient une **couleur de texte** en blanc

### Conseils

- Pas de pièges ici : faîtes simplement comme la semaine dernière, avant de découvrir les classes ou les ids. Il s'agit d'une révision de ce que vous savez -normalement- déjà faire.
- Ne vous fiez pas qu'au résultat dans le navigateur : relisez les consignes et relisez votre code !
