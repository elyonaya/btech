# Jour 4 : CSS Selectors

## Exercice 5 :

Créez un fichier "index.html avec :

- une **liste non-ordonnée** avec trois **éléments de liste**
- trois **boutons** (après la liste)

Créez un fichier "styles.css" avec :

- une **couleur de fond** identique à chaque **élément de liste**
- une **couleur de fond** différente à chaque **bouton**
- un changement de **couleur de fond** d'un **élément de liste** lorsqu'on **passera** la souris dessus
- un changement de **couleur de fond** d'un **bouton** lorsqu'on **cliquera** dessus

## Conseils

- Si vous avez bien lu : on ne devra pas utiliser directement un sélecteur de type "**balise**".
- Ne vous fiez pas qu'au résultat dans le navigateur : relisez les consignes et relisez votre code !
